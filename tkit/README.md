# Daycare Permata Hati Bekasi

Website unit mandiri. Semua halaman, CSS, JavaScript, dan media berada di folder ini.

- URL publik: `/daycare/`
- Admin: `/daycare/admin/`
- Data menggunakan database `school_units_portal`, terpisah dari website yayasan.
- Media baru yang diunggah dari admin disimpan di `assets/uploads/` unit terkait.

Konten awal otomatis dibuat saat website pertama kali dibuka. Pengaturan nama, kontak, WhatsApp, peta, dan media dapat dikelola lewat portal admin.
